# Yoop API

REST API built with Laravel 12, Sanctum, Stripe and Didit KYC.

---

## Requirements

- [Docker](https://docs.docker.com/get-docker/) + Docker Compose
- [Stripe CLI](https://stripe.com/docs/stripe-cli) _(for webhook forwarding in local dev)_

### Installing Docker on a fresh VPS (Ubuntu/Debian)

```bash
# 1. Install Docker
curl -fsSL https://get.docker.com | sh

# 2. Add your user to the docker group (avoids using sudo every time)
usermod -aG docker $USER && newgrp docker
```

> Docker Compose v2 is included with Docker — no separate installation needed.

## Getting started

### 1. Clone the repository

> This is a private repository. Make sure you have access and an SSH key configured, or use a personal access token.

```bash
# Via SSH (recommended)
git clone git@github.com:BrunohTrindade/yoop.git
cd yoop

# Via HTTPS (will prompt for credentials)
git clone https://github.com/BrunohTrindade/yoop.git
cd yoop
```

### 2. Configure environment

```bash
cp .env.docker .env
```

Open `.env` and fill in the required values:

```env
# App
APP_KEY=          # generate with: docker compose run --rm app php artisan key:generate --show
APP_URL=http://localhost

# Database
DB_DATABASE=yoop
DB_PASSWORD=secret   # choose a strong password

# Stripe
# Add STRIPE_KEY and STRIPE_WEBHOOK_SECRET via the settings table (see step 5)

# Didit KYC
DIDIT_API_KEY=
DIDIT_API_SECRET=
DIDIT_WORKFLOW_ID=
```

### 3. Build and start containers

```bash
docker compose up -d --build
```

This will:
- Build the PHP image
- Start MySQL, Redis, Nginx and the queue worker
- Run `php artisan migrate` automatically on startup

Check all containers are running:

```bash
docker compose ps
```

### 4. Generate application key (first run only)

```bash
docker compose exec app php artisan key:generate
```

### 5. Seed initial settings

```bash
docker compose exec app php artisan db:seed
```

If you need to insert Stripe keys manually:

```bash
docker compose exec app php artisan tinker
```

```php
\App\Models\Setting::updateOrCreate(['key' => 'stripe_key'],            ['value' => 'sk_live_...']);
\App\Models\Setting::updateOrCreate(['key' => 'stripe_public_key'],     ['value' => 'pk_live_...']);
\App\Models\Setting::updateOrCreate(['key' => 'stripe_webhook_secret'], ['value' => 'whsec_...']);
```

### 6. Stripe webhook (local development)

Forward Stripe events to your local API:

```bash
stripe listen --forward-to http://localhost/api/webhooks/stripe
```

Copy the webhook signing secret shown and insert it into the settings table (step 5).

## Useful commands

```bash
# View logs
docker compose logs -f app
docker compose logs -f queue

# Run artisan commands
docker compose exec app php artisan <command>

# Run migrations
docker compose exec app php artisan migrate

# Restart queue worker
docker compose restart queue

# Stop all containers
docker compose down

# Stop and remove volumes (destroys database data)
docker compose down -v
```
